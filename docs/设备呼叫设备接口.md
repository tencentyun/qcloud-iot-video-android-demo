# 1. 功能介绍

本模块用于设备呼叫对端设备并拉取对端设备流进行观看功能。

# 2. 使用流程

## 2.1 基本流程

```shell
iv_client_create // 创建client句柄
				|
iv_client_setup_connect // 连接对端设备
				|
iv_client_start_recv_stream // 启动收流
				|
iv_client_start_send_stream // 启动发送数据，如何需要，不需要可不用调用
				|
while(1) // 主循环
				|
iv_client_stop_recv_stream // 停止收流
				|
iv_client_stop_send_stream // 停止发送数据，如何需要
				|
iv_client_teardown_connect // 关闭链接
				|
iv_client_destroy // 销毁client句柄
```

# 3. 接口参考

## 3.1 接口列表

> 该功能模块提供如下接口

- iv_client_create() 创建client句柄
- iv_client_destroy() 销毁client句柄
- iv_client_setup_connect() 发起对端链接
- iv_client_teardown_connect() 关闭链接
- iv_client_start_recv_stream() 开始收流
- iv_client_stop_recv_stream() 停止收流
- iv_client_start_send_stream() 开始发送数据
- iv_client_stop_send_stream() 停止发送数据
- iv_client_send_stream() 发送数据
- iv_client_get_send_buffer_size() 获取发送水位

## 3.2 接口描述

### 3.2.1 iv_client_create

- 功能描述

  初始化client句柄，并设置回调函数与用户自定义参数。

- 函数原型

  ```c
  struct iv_client_t;
  struct iv_client_t* iv_client_create(const struct iv_client_func_t *func, void* param);
  ```

- 参数说明

  | 参数名称 | 类型                            | 描述                 | 输入/输出 |
  | -------- | ------------------------------- | -------------------- | --------- |
  | func     | const struct iv_client_func_t * | client回调接口结构体 | 输入      |
  | param    | void*                           | 用户自定义数据       | 输入      |

- 返回值

  | 返回值类型          | 描述       |
  | ------------------- | ---------- |
  | struct iv_client_t* | client句柄 |

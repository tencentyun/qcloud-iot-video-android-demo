# 1. 功能介绍
本模块用于设备端配网


# 2. 使用流程

## 摄像头扫描小程序二维码配网
1. 启动“腾讯连连”小程序，按提示进行操作
2. 使用IPC摄像头扫描小程序生成的配网二维码，扫描后的内容类似如下
    ```
    {
        "SSID": "my_wifi",
        "password": "my_password",
        "token": "12345678901234567890"
    }
    ```
3. 根据上述信息连接wifi（有线设备忽略）
4. 连接完成后调用 iv_sys_init(), iv_dm_init() 初始化必要的功能模块
5. 调用 iv_ad_send_bind_info() 上报上述配网token
6. 上报成功后刷新小程序主页面即可看到刚刚添加的设备
7. 在需要解绑设备时，可以通过调用iv_ad_unbind_device_request解除和用户账号的绑定


# 3. 接口参考

## 接口列表
**该功能模块提供以下接口**  
* int iv_ad_send_bind_info(char *pToken, int32_t time_out) 上报配网token至服务器
* int iv_ad_unbind_device_request(int time_out)   进行设备和用户账号的解绑


## 接口描述

### iv_ad_send_bind_info

**函数原型**  
```
int iv_ad_send_bind_info(char *pToken, int time_out)
```

**功能描述**  
上报配网token至服务器，阻塞式调用，超时时间建议设置在2秒以上

**参数说明**  
| 参数名称 | 类型   | 描述                                  | 输入/输出 |
| -------- | ------ | ------------------------------------- | --------- |
| pToken   | char * | 配网token                             | 输入      |
| time_out | int    | 超时时间（单位毫秒，不得小于200毫秒） | 输入      |

**返回值**  
| 返回值      | 描述                 |
| ----------- | -------------------- |
| IV_ERR_NONE | 成功                 |
| IV_ERR_*    | 失败，对应相应错误码 |

### iv_ad_unbind_device_request

**函数原型**
```
int iv_ad_unbind_device_request(int time_out)
```

**功能描述**
解绑设备，阻塞式调用，超时时间建议设置在2秒以上

**参数说明**  
| 参数名称 | 类型   | 描述                                  | 输入/输出 |
| -------- | ------ | ------------------------------------- | --------- |
| time_out | int    | 超时时间（单位毫秒，不得小于200毫秒） | 输入      |


# 4. 注意事项
1. 二维码扫描及解析功能、wifi连接功能需用户自行实现
2. 必须依次调用 iv_sys_init(), iv_dm_init() 返回成功且设备上线后再进行其他操作
